物理模型是定性的简化模型：升力 L = c·ω²（ω 为翼角速度），升力中心随翼角前后移动产生俯仰力矩，左右升力差产生滚转力矩， 阻力作用在翼面（高于重心）产生摆锤回正；舵机 600°/s 速度上限。参数只用来看懂控制链路怎么工作，不代表真机。 IMU 数据来自仿真：真实角速度 + 零偏 + 噪声，比力 = Rᵀ(a−g)；上电 1 s 静止校准零偏，和固件一样。
