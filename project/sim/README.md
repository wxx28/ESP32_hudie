# 仿生蝴蝶飞行仿真（适配本仓库飞控代码）

在电脑上运行**仓库里真实的飞控代码**，配一个简化的扑翼物理模型，用浏览器看蝴蝶飞、拨遥控、注入故障、调参数。

```
浏览器 (web/index.html)  ⇄  server.js (Node, SSE + POST)  ⇄  hudie_sim (C，stdin/stdout)
                                                              ├─ 真实代码：Middlewares/algo/*.c、fc_output.c、fc_config.c、hudie_protocol.c
                                                              └─ 仿真：遥控器 / 无线信道 / 400 Hz 调度 / 舵机 / 6 自由度机体 / IMU / 电池
```

## 运行

Windows：双击 `start.bat`（会自动打开 http://localhost:8090）。或者：

```bash
cd project/sim
./build.sh          # 需要 gcc（Windows 用 MSYS2 mingw64）
node server.js      # 打开 http://localhost:8090
```

`server.js` 发现代码比仿真内核新时会自动重新编译——改了 `algo/` 或 `flight_control/` 的代码，重启服务就能看效果。

## 界面

| 区域 | 内容 |
|---|---|
| 3D 视图 | 蝴蝶（翼角来自物理模型里舵机的实际位置）、轨迹、影子、飞控 LED2。拖动旋转、滚轮缩放；跟随机头 / 俯视 / 侧视 / 远景 |
| 姿态球 | 白 = 真实姿态，黄 = 飞控 Mahony 估计 |
| 曲线（10 s） | 舵机角（指令/实际）、横滚、俯仰（真实/估计）、高度/油门 |
| 状态 | 安全状态机状态、两个指示灯（节奏与固件一致）、遥控帧龄、丢包、幅度/差动限制、控制量、电池、故障标志、事件日志、操作提示 |
| EDU 遥控器 | 两个摇杆（可拖动）和按键，逻辑同 `rc_app.c`：油门 > 5% 拒绝解锁、模式切换、陀螺校准、微调 |
| 故障注入 | 断开链路、丢包率、阵风、侧风、IMU 失效、右舵机装反、电池加速消耗/更换 |
| 飞控参数 | 机构已确认、增稳已整定、角度/角速度 PID、降级幅度、失控油门。点"应用"＝改 menuconfig 后重新烧录（飞控重新自检） |

键盘：`W/S` 油门，`A/D` 偏航，方向键 横滚/俯仰（按住 Shift 满杆），`空格` 解锁/上锁，`M` 模式，`C` 校准，`X` 油门到底，`P` 暂停。也支持手柄。

## 可以试的东西

1. **解锁规则**：油门推高再按解锁 → 被拒绝；飞控还在自检时按解锁 → 遥控显示解锁但飞控不解锁，必须上锁再解锁。
2. **手动 vs 增稳**：手动打 50% 横滚杆会翻到 50° 以上；勾选"增稳已整定"、遥控切到增稳后同样的杆量只有 10° 左右，阵风后自动回平。
3. **失控保护**：飞到 5 m 后断开链路 → 0.3 s 降级、1 s 失控保护、约 0.5 m/s 缓降；把失控油门调到 0.35（原 algo 默认）再试 → 坠地。
4. **调 PID**：把角速度 P 调到 1.0 看振荡，调到 0 看增稳失效。
5. **硬件故障**：IMU 失效 → 立即急停（会掉下来）；右舵机装反 → 两翼反向拍动，机身左右剧烈摇摆（角速度 100°/s 级），这就是台架要先确认方向的原因。

## 物理模型（简化，定性）

- 升力 L = c·ω²（ω 为翼角速度），c 按"理想条件 65% 油门悬停"标定；
- 升力中心随翼角前后移动 → 俯仰力矩（上下拍不对称就能控俯仰）；左右升力差 → 滚转力矩；
- 升力垂直于翼面（翼抬起时向内倾），翼的转动惯量反作用到机身；对称扑动时两者抵消，反向扑动时引起左右摇摆；
- 阻力作用在翼面（高于重心）→ 侧滑时回正（摆锤稳定）；线性角阻尼；
- 舵机：一阶滞后 6 ms + 600°/s 速度上限；直驱，翼角 = (舵机角 − 中位) × 方向；
- IMU：真实角速度 + 随机零偏 + 噪声，比力 = Rᵀ(a − g) + 噪声；扑翼带来的振动自然出现在信号里；
- 电池：1S 500 mAh，电流随升力变化。

参数是为了看懂控制链路而选的，**不代表真机数值**；真机的悬停油门、PID、失控油门必须实测。

## 仿真发现并已修复的问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 失控油门设成比降级幅度高也没用 | 失控斜坡只会往下降 | `algo_safety.c` 改成双向过渡 |
| 爬升中断链，蝴蝶一直往上飞 | 失控时保持最后油门 | 失控时油门过渡到"失控油门"并保持（缓降） |
| 原 algo 默认失控幅度 0.35 会以 ~4 m/s 坠地 | 升力 ≈ 幅度²，0.35 只剩 12% 升力 | V1 配置新增 `FC_FAILSAFE_THROTTLE_PCT`（默认 60）、`FC_DEGRADED_AMP_PCT`（默认 85） |
