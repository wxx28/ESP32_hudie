# 01 · 飞控算法选型：怎么做才算"最稳"

> 适用对象：2 舵机、周期拍翅、欠驱动的仿生蝴蝶。先给结论，再给依据、公式和整定流程。

---

## 0. 一句话结论

**Mahony 互补滤波 + 串级 PID（角速度 400Hz / 角度 100Hz）+ 拍翅相位同步前馈 + 增益调度。**
不要上 EKF/MPC/强化学习。真正决定"稳不稳"的不是滤波器多高级，而是这四件事：**左右机构对称、控制与拍翅相位锁定、IMU 减振、以及前馈补偿周期性气动力矩**。

---

## 1. 为什么不用 EKF（很多人第一反应都是 EKF）

| 维度 | Mahony | EKF（15 状态） |
|---|---|---|
| 单次耗时（C3 @160MHz） | 约 40–60µs | 约 400–800µs（含矩阵运算） |
| 400Hz 下 CPU 占用 | 2–3% | 16–32%，还要和 WiFi 任务抢 |
| 参数个数 | 2（Kp、Ki） | 十几个（Q/R/P0） |
| 周期性振动 | PI 结构"钝"，天然抗 | 会被当成真实运动，Q/R 调不好就发散或严重滞后 |
| 磁干扰（LIS2MDL 靠近电池/电感） | 可关掉磁力计 | 融合进去会把干扰带进姿态 |
| 台架调参时间 | 10 分钟 | 半天起，且要重新标定 |

结论：在"单核 + 强周期振动 + 磁环境脏"的组合下，EKF 是负收益。**Mahony 的"钝"在这里是优点。**

### 备选方案对比

| 方案 | 精度 | 算力 | 抗周期振动 | 调参 | 结论 |
|---|---|---|---|---|---|
| Mahony | 中 | 极低 | 好 | 易 | ✅ 首选 |
| Madgwick | 中 | 低 | 中 | 中（β） | 备选，效果接近 |
| 一阶互补滤波 | 低 | 极低 | 好 | 极低 | 台架快速验证可用 |
| EKF 15 状态 | 高 | 高 | 差 | 难 | ❌ 单核 C3 不划算 |
| LQR / MPC | — | 高 | — | 极难 | ❌ 没有可信模型 |
| 强化学习 | — | 高 | — | — | ❌ 首次飞行不用 |
| CPG / 相位振荡器 | — | 低 | — | 中 | ✅ 只用来产生拍翅相位 |

## 2. 传感器配置与采样

| 项目 | 取值 | 理由 |
|---|---|---|
| 总线 | SPI，8MHz | MPU6500 单次读 14 字节约 15µs |
| 陀螺量程 | ±1000 dps | 拍翅瞬间机体角速度可达 ±200–400dps，±250 会溢出 |
| 加速度量程 | ±8g | 拍翅冲击大，±2g 会削顶 |
| DLPF | 20Hz 硬件 + 30Hz 软件二阶低通 | 拍翅 7–9Hz，控制带宽留到 12–15Hz |
| 采样率 | 400Hz | 2.5ms 一拍，与舵机 PWM 周期对齐 |
| 数据就绪 | **轮询**（INT 未接 MCU） | 原理图已确认 `INT` 网络只出现 1 次 |
| I2C（磁/气压） | 50Hz、400kHz | 不参与内环，只做辅助 |
| 陀螺零偏 | 静止 2s 采 2000 点取均值，存 NVS | 每次上电自动校准 |

### 振动是头号敌人

拍翅 7–9Hz 的周期性机体振动会直接灌进陀螺。两手一起上：

1. **机械**：飞控板用硅胶减振柱（M2 橡胶垫）安装，别用硬铜柱；IMU 尽量靠近重心。
2. **软件**：陀螺 30Hz 二阶低通 + **拍翅相位同步平均**——因为拍翅相位是我们自己产生的（见第 4 节），可以把陀螺信号分解为"与拍翅同相位的周期分量"和"剩余分量"，控制只用剩余分量。这一步能把 7–9Hz 抖动压掉 80% 以上，比换滤波器有效。

## 3. Mahony 姿态解算

四元数 $q$，角速度 $\omega$，加速度计观测的重力方向 $\hat g$，估计重力方向 $\hat v = R(q)^T[0,0,1]$：

$$\dot q = \tfrac12 q \otimes \big(\omega + K_p\, e + K_i\!\int e\,dt\big),\qquad e = \hat g \times \hat v$$

| 参数 | 建议初值 | 说明 |
|---|---|---|
| $K_p$ | 1.5 | 1.0–2.0；400Hz 下约 0.7s 时间常数 |
| $K_i$ | 0.01 | 0.005–0.02，消陀螺零偏 |
| 磁力计增益 | 0.05（默认关） | 只在 \|acc\|≈1g 且 \|ω\|<50dps 时更新航向 |

磁力计先关：LIS2MDL 离电池和升压电感很近，等整机装好、实测干扰后再决定是否开。

```
每 2.5ms:
    imu.read(acc, gyr)            # SPI
    gyr = lpf2(gyr, 30Hz)         # 二阶低通
    q   = mahony(q, gyr, acc, dt) # Kp=1.5, Ki=0.01
    att = euler(q)                # roll/pitch/yaw (deg)
```

## 4. 控制结构：三级 + 一个相位发生器

```
油门 CH1 ──► 拍翅频率 f (5–7Hz) ──► 相位发生器 ψ += 2πf·dt ──┐
                                                                │
IMU 400Hz ─► Mahony ─► 姿态 ─► 角度环 100Hz ─► 角速度环 400Hz ─┤
                                                                ▼
                                                        前馈 u_ff(ψ)（相位查表）
                                                                │
                                            ┌───────────────────┴───────────────────┐
                                            ▼                                       ▼
                                  混控：幅度/偏置/相位差                舵机逆解（四杆机构）
                                            │                                       │
                                   θs_L, θs_R ──► 反相 LEDC ──► 光耦 ──► PWM_L/R
```

### 4.1 相位发生器（"心脏"）

$\psi \mathrel{+}= 2\pi f\,\Delta t$，$f$ 由油门通道映射（建议 5.5–9.0Hz，对应悬停/爬升（构型 A 常用 7–8Hz））。
**控制量只在 $\psi$ 的固定相位点更新**（例如每 60° 更新一次，或过零点更新），而不是每个控制周期都变。原因：如果舵机指令与拍翅相位不同步，等于在 7–9Hz 上叠加一个随机调制，机体就会"抖"和"爬升不稳"。这是本方案与"直接把多旋翼 PID 搬过来"最大的区别。

### 4.2 串级 PID

| 环 | 频率 | 形式 | 初值 |
|---|---|---|---|
| 角速度环 | 400Hz | PID + 前馈，输出限幅 ±100% | P=0.8, I=0.08, D=0.002 |
| 角度环 | 100Hz | P，输出限幅 ±150dps | P=3.0 |
| 偏航 | 400Hz | 角速度阻尼（无磁力计闭环） | P=0.5 |

积分限幅 ±30%，输出速率限制（舵机每拍最多动 3°），防止舵机被指令"打满"。

### 4.3 混控（通道 → 四个自由度）

| 通道 | 映射 | 说明 |
|---|---|---|
| CH1 油门 | 拍翅频率 f 与基准幅度 A₀ | 5.5–9Hz，A₀=±35°~±60° |
| CH2 俯仰 | 两翼平均行程偏置 `offset` | 改变拍翅平面倾角 → 俯仰力矩 |
| CH3 滚转 | 差动幅度 `A_L = A₀+u_roll`，`A_R = A₀-u_roll` | 左右升力差 → 滚转 |
| CH4 偏航 | 两翼相位差 δ：`ψ_R = ψ_L + δ` | 反扭矩不对称 → 偏航 |
| CH5 模式 | 增稳 / 手动 / 校准 | 开关 |
| CH6 解锁 | 电机/拍翅使能 | 开关，双段确认 |

翼角 → 舵机角的映射：

```
α_L(ψ) = A_L·sin(ψ) + offset + u_pitch
α_R(ψ) = A_R·sin(ψ + δ) + offset + u_pitch
α 限幅 ±60°（机械限位 ±68°）
θs = inv_link(α)        # 四杆机构逆解（查表，见 02 文档）
duty = period - pulse(θs)   # 光耦反相
```

`inv_link` 不要省：四杆机构在大行程时舵机角与翼角明显非线性，用固定比例会把控制增益带偏。

## 5. 前馈：把周期性力矩"提前"补掉

拍翅产生的力矩是周期性的，PID 带宽（约 5–10Hz）追不上 7–9Hz 的扰动。前馈可以：

$$u_{ff}(\psi) = a_1\sin\psi + b_1\cos\psi + a_2\sin 2\psi + b_2\cos 2\psi$$

辨识方法（台架，2 小时）：

1. 固定油门、固定幅度，让机构空转；
2. 在某一翼上加已知小偏置（例如 +2°），同步记录机体角速度；
3. 扫 12–16 个相位点，对每个相位点的角速度响应做最小二乘，拟合 $a_1..b_2$；
4. 把系数写进 `config.h`，前馈常开。

**效果**：周期性扰动被前馈吃掉，PID 只修慢漂和非周期扰动，姿态抖动可以降一个量级。这是"最稳"的实际来源，比换 EKF 有用得多。

## 6. 单核时序设计（ESP32-C3 特有，必须提前规划）

ESP32-C3 只有**一个核**，WiFi/ESP-NOW 任务优先级高于 Arduino `loop()`，会打断控制循环。设计原则：

| 任务 | 频率 | 实现方式 | 注意 |
|---|---|---|---|
| IMU 采样 + 姿态 | 400Hz | `esp_timer` 置标志，主循环里执行 | 不要在定时器回调里做 SPI |
| 控制 + 混控 | 400Hz | 主循环（与 IMU 同拍） | 计算量控制在 300µs 内 |
| 舵机 PWM | 250–333Hz | **LEDC 硬件** | 与 CPU 抖动无关，这是关键 |
| 遥控接收 | 50Hz | ESP-NOW 回调 → 环形队列 | 回调里只 memcpy，不做计算 |
| 遥测发送 | 20Hz | 主循环 | 16–32 字节 |
| 日志 | 10Hz（可关） | USB CDC / UART | 调试时才开 |

硬性规定：`loop()` 里禁止 `delay()`、禁止 `Serial.print`、禁止长 I2C 事务。I2C 只读 50Hz。

## 7. 整定流程（按顺序，别跳步）

| 步骤 | 内容 | 通过标准 |
|---|---|---|
| 0 | 舵机中位、行程、反相确认 | 两个舵机同指令同向；脉宽 500–2500µs 对应 ±60° |
| 1 | IMU 零偏 + Mahony 收敛 | 板子倾斜 30°，读数和量角器差 <2° |
| 2 | 单翼推力-幅度台架 | 左右同幅度推力差 <5% |
| 3 | 前馈相位辨识 | $a_1..b_2$ 写入配置 |
| 4 | 系绳：角速度环 P→I→D | 阶跃无持续振荡 |
| 5 | 系绳：角度环 P | 超调 <20%，2s 内稳定 |
| 6 | 系绳：滚转/俯仰阶跃 | 记录上升时间/超调，形成参数表 |
| 7 | 自由飞：滑翔（关拍翅）→ 小幅度拍翅 → 加油门 | 逐级放行 |

## 8. 失控与保护（必须有，不是可选）

| 条件 | 动作 |
|---|---|
| 遥控超时 300ms | 拍翅幅度线性降到 0，翼展平，俯仰配平滑翔 |
| 超时 1s | 进入迫降：小幅拍翅 + 缓慢下降 |
| 姿态 >60° 持续 0.5s | 切断拍翅（防止翻滚加剧） |
| 电池 <3.4V | 报警 + 迫降 |
| 上电自检失败（SPI/I2C 器件不在位） | 状态灯闪码，拒绝解锁 |
| 解算发散（四元数范数异常） | 复位姿态到加速度计重力方向 |
