# 03 · 遥控链路与协议（独立无线遥控器 ↔ 机上 ESP32-C3）

> 结论：**用 ESP-NOW 做纯无线控制**。遥控器是一台**独立手持设备**（自带电池、电源开关、天线，飞的时候不插任何线），机上就是板载 ESP32-C3，2.4G 点对点直连：50Hz 控制帧 + 20Hz 遥测回传，同一条链路。
> USB 只在两种情况下用：**给遥控器充电**、**烧录固件**。飞行中遥控器和飞机之间没有任何线缆。
> 备选：板上留了 SBUS 输入（P2.1，经 Q1 反相进 RXD0），可以外接成品接收机做备份链路。

---

## 0. 遥控器的"无线"是怎么保证的

| 环节 | 做法 | 为什么要这样做 |
|---|---|---|
| 遥控器供电 | 内置 1S 1000 mAh 锂电 + TP4056 充电板 + 拨动电源开关 | 手持使用时完全无线的前提；USB 只充电 |
| 遥控器主控 | ESP32-DevKitC（或 C3 SuperMini）自带 2.4G 射频 | 不需要外接发射模块 |
| 遥控器天线 | 板载 PCB 天线，竖直朝向飞机 | 天线被手/铝壳遮挡会直接掉距离 |
| 通信 | ESP-NOW 点对点（无需路由器、无需手机、无需配网） | 上电即通，延迟 2–5 ms 量级 |
| 飞行中插线 | **不允许**（USB 只充电/烧录） | 插线等于把遥控器变成有线，且共地引入干扰 |
| 断链 | 300 ms 幅度归零、1 s 迫降 + 遥控器蜂鸣 | 无线链路必须有失控保护 |
| 电量 | OLED 显示遥控器电池电压，低于 3.5 V 蜂鸣 | 防止"遥控器先没电"导致失控 |

> 一句话：**遥控器 = 一块电池 + 一块 ESP32 + 两个摇杆 + 两个开关 + OLED，开机即连，无任何线缆。** 具体 BOM 见第 4 节。

## 1. 为什么是 ESP-NOW

| 方案 | 延迟 | 距离 | 额外硬件 | 结论 |
|---|---|---|---|---|
| **ESP-NOW** | **2–5 ms 量级** | 200–500 m（视天线/遮挡），LR 模式更远 | 无（ESP32 自带） | ✅ 首选 |
| WiFi UDP（AP/STA） | 10–50 ms，抖动大 | 100 m 级 | 无 | ❌ 抖动大，还要配网 |
| BLE | 7.5–30 ms（连接间隔限制） | 30–100 m | 无 | ❌ 延迟不稳 |
| LoRa（SX127x） | 50–500 ms | 几 km | 模块 | ❌ 速率不够控制 |
| 专用 RC（ELRS 等） | 2–10 ms | 几 km | 接收机 + 发射模块 | 可用，但要额外采购；板上 SBUS 口可接 |
| 433MHz 遥控模块 | 20–50 ms | 100 m 级 | 模块 | ❌ 只适合开关量 |

ESP-NOW 的关键优势：**无连接、无需路由、无需配网**，上电即通；而且单播发送在 MAC 层有确认（发送回调返回 `ESP_NOW_SEND_SUCCESS` 才代表对端 MAC 收到了），天然能算丢包率。协议细节见 [ESP-IDF ESP-NOW 文档](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/network/esp_now.html)。

注意两点：

1. ESP32-C3 **只有一根天线**，ESP-NOW 占用的就是 WiFi 射频：跑 ESP-NOW 时不要同时开 AP/STA 连接（会分时，增加抖动）。
2. 默认速率 1 Mbps；需要远距离时两端都开 **LR 模式**（`WIFI_PROTOCOL_LR`，802.11 长距离模式），代价是速率下降、单包时间变长。50Hz × 18 字节的负载在 LR 下也够用。

## 2. 链路预算（先按 150m 半径飞）

| 项目 | 数值 |
|---|---|
| 发射功率 | 20 dBm（可降到 8–11 dBm 省电，近距离够用） |
| 接收灵敏度 | 约 -97 dBm（1Mbps） |
| 理论视距 | 1–2 km |
| 实际（机身遮挡 + 天线姿态） | 200–500 m |
| 首飞建议半径 | **100–150 m**，先做距离拉距测试 |
| 控制帧率 | 50Hz（20ms） |
| 端到端延迟 | 遥控采样 + 空口 + 接收 + 控制 + 舵机 ≈ **25–35 ms** |

## 3. 协议帧定义

两端共用一份头文件（下一步 `firmware/shared/protocol.h`），小端、`__attribute__((packed))`。

### 3.1 控制帧（遥控器 → 机，50Hz）

```c
#define PROTO_VER   1
#define TYPE_RC     0x01
#define TYPE_TELEM  0x02
#define TYPE_BIND   0x03

typedef struct __attribute__((packed)) {
    uint8_t  ver;        // PROTO_VER
    uint8_t  type;       // TYPE_RC
    uint8_t  seq;        // 递增，用于统计丢包
    uint8_t  flags;      // bit0 armed, bit1 mode(0=增稳/1=手动), bit2 calibrate, bit3 bind
    int16_t  ch[6];      // 通道值 -1000..+1000（CH1 油门 0..+1000）
    uint16_t crc;        // CRC16-CCITT，覆盖前面所有字节
} rc_frame_t;            // 18 字节
```

| 通道 | 名称 | 范围 | 映射 |
|---|---|---|---|
| ch[0] | 油门/拍翅 | 0..1000 | 5.5–9.0Hz + 基准幅度 0–±60° |
| ch[1] | 俯仰 | -1000..1000 | 两翼平均行程偏置 |
| ch[2] | 滚转 | -1000..1000 | 左右差动幅度 |
| ch[3] | 偏航 | -1000..1000 | 左右相位差 δ |
| ch[4] | 模式 | -1000/0/1000 | 三档：校准/增稳/手动 |
| ch[5] | 解锁 | 0/1000 | 双段确认（见安全性） |

### 3.2 遥测帧（机 → 遥控器，20Hz）

```c
typedef struct __attribute__((packed)) {
    uint8_t  ver, type, seq, state;   // state: 0 自检 1 校准 2 待解锁 3 飞行 4 迫降 5 故障
    int16_t  roll, pitch, yaw;        // 0.1° 单位
    int16_t  gyro[3];                 // dps
    uint16_t vbat_mv;                 // 电池电压 mV
    int16_t  alt_cm;                  // 气压高度 cm（相对起飞点）
    uint8_t  rssi_dbm;                // 遥控器侧填入，或机上用 rx_ctrl 估算链路
    uint8_t  loss_pct;                // 本机统计的丢包率 %
    uint16_t crc;
} tele_frame_t;                       // 24 字节
```

### 3.3 绑定帧（双向）

```c
typedef struct __attribute__((packed)) {
    uint8_t ver, type, cmd;   // cmd: 1 请求绑定, 2 绑定确认, 3 解绑
    uint8_t mac[6];           // 发起方 MAC
    uint16_t crc;
} bind_frame_t;
```

- 首次使用：遥控器按住绑定键上电，机上上电后 10s 内处于可绑定状态；双方交换 MAC 写入 NVS。
- 之后上电自动连接，无需再绑。
- ESP-NOW 单播默认不加密；想加一层就设 PMK/LMK（16 字节），两端一致即可。

## 4. 遥控器硬件（独立无线手持方案）

| 部件 | 建议 | 说明 |
|---|---|---|
| 主控 | ESP32-DevKitC（经典双核）或 ESP32-C3 SuperMini | 经典版 ADC 更好选脚；自带 2.4G 射频 |
| 左摇杆 | KY-023 双轴电位器 | 油门/偏航（或油门+滚转，按手感） |
| 右摇杆 | KY-023 | 俯仰/滚转 |
| 开关 | 2 个三段拨动开关 | 模式、解锁 |
| 显示 | 0.96" SSD1306 OLED（I2C） | 显示飞机电压/姿态/丢包率 + 遥控器自身电量 |
| 蜂鸣器 | 有源蜂鸣器 + NPN | 低电/失控/绑定提示 |
| **电池** | **1S 1000 mAh 锂电（约 20 g）** | 独立供电，续航约 4–6 h（ESP-NOW 50Hz + OLED） |
| **充电** | TP4056 模块（Type-C 口） | 只在充电时插线 |
| **电源开关** | 拨动开关串在电池与 ESP32 之间 | 飞行前打开，飞完关掉 |
| 外壳 | 3D 打印 | 摇杆阻尼用硅胶垫；天线区域不要包金属/碳纤维 |

### 4.0 上电与使用流程（全无线）

1. 打开遥控器电源开关 → OLED 亮、蜂鸣一声 → 显示"等待飞机"；
2. 飞机上电（电池开关 S1）→ 自动配对（已绑定过 MAC）→ OLED 显示电压/姿态；
3. 推油门解锁 → 起飞；飞行中遥控器与飞机之间**没有任何线缆**；
4. 落地后先关飞机、再关遥控器；USB 只在给遥控器充电或烧录时插。

### 4.1 引脚建议（ESP32 经典双核）

| 功能 | GPIO | 注意 |
|---|---|---|
| 左摇杆 X（油门） | IO34 | 仅输入，ADC1 |
| 左摇杆 Y | IO35 | ADC1 |
| 右摇杆 X | IO32 | ADC1 |
| 右摇杆 Y | IO33 | ADC1 |
| 模式开关 | IO25 | 三段：两个输入脚 |
| 解锁开关 | IO26 | |
| 绑定键 | IO27 | 上拉输入 |
| OLED SDA / SCL | IO21 / IO22 | I2C |
| 蜂鸣器 | IO23 | |
| 遥控器电池采样 | IO36 | 100K/100K 分压（与飞机同一套算法） |

> **重要**：ESP32 的 ADC2 与 WiFi 冲突，摇杆只接 **ADC1（IO32–39）**。若用 C3 SuperMini，摇杆接 IO0–IO4（避开 IO8/IO9 启动脚），OLED 用 IO5/IO6。

### 4.2 摇杆处理

- 12 位 ADC，每通道采 8 次取中位数再平均，抑制抖动；
- 校准：上电时记录中位与两端极限，做 `map` + 死区（±30 LSB）+ 指数曲线（expo 0.3，手感更细腻）；
- 50Hz 发送，`seq` 递增；发送回调统计成功率。
- 油门通道映射到拍翅频率/幅度：**5.5–9 Hz**（本方案常用 7.0–7.5 Hz，上限 8 Hz）。

## 5. 失控保护（状态机）

| 条件 | 动作 | 恢复 |
|---|---|---|
| 连续 300ms 没收到有效控制帧 | 拍翅幅度线性降到 0，翼展平，俯仰配平滑翔 | 收到 3 帧有效数据自动恢复 |
| 连续 1s 没收到 | 进入迫降（小幅拍翅 + 缓慢下降），状态灯慢闪 | 需重新解锁 |
| 收到帧但 CRC/版本错误 | 丢弃并计数，不触发失控（避免误判） | — |
| 遥控器端 1s 没收到遥测 | 蜂鸣器报警 + OLED 显示"失控"，同时继续发控制帧 | 自动恢复 |
| 电池 <3.4V | 机上遥测标记低电，遥控器蜂鸣 | 降落换电池 |

机上状态机：`自检 → 校准 → 待解锁 → 飞行 ⇄ 迫降`，任何异常进 `故障` 并切断拍翅。

## 6. SBUS 备份链路（板载资源，可选）

板上 P2.1 是 `SBUS`，经 Q1(S8050) 反相后进 `RXD0`(IO20)。接成品 SBUS 接收机时：

| 项目 | 设置 |
|---|---|
| 电平 | SBUS 是反相 100kbps 串口；Q1 已经反相一次，所以软件按**正相**收 |
| 串口 | UART0：`100000 bps, 8E2`（8 数据位、偶校验、2 停止位） |
| 帧格式 | 25 字节 `0x0F ... 0x00`，8 通道 × 11bit + 2 个标志位 |
| 失控帧 | 标志字节 bit2=1 且通道全 0 → 视为失控 |
| 优先级 | 默认用 ESP-NOW；检测到 SBUS 有效帧可切 SBUS（编译开关） |

## 7. 天线与频谱注意事项

1. 天线远离碳纤维机架、电池和升压电感——碳纤维会屏蔽 2.4G，这是最常见的"飞 50m 就失控"原因。
2. 遥控器天线竖直，飞机天线尽量水平或与遥控器正交，避免"零陷"。
3. 信道选 1/6/11 中较干净的一个，两端一致；不要和现场路由器同信道。
4. 首飞前做拉距测试：一个人拿飞机走 100m/200m，记录丢包率（<5% 可飞）。
5. 校准时（地面静止）关掉电机/舵机负载，避免电流噪声影响 ADC 采样。

## 9. 验收测试

| 测试 | 方法 | 通过标准 |
|---|---|---|
| 连通性 | 上电互发 1000 帧 | 丢包 <1%（1m 距离） |
| 延迟 | 遥控器打杆，示波器看舵机输出 | 端到端 <40ms |
| 拉距 | 100m / 200m / 300m | 100m 丢包 <5%；失控保护动作正确 |
| **无线独立性** | 飞行中拔掉所有 USB/数据线，只留遥控器电池 | 全流程无掉线（这是"无线控制"的验收条件） |
| **遥控器续航** | 满电连续开机 2 h，50Hz 发送 + OLED | 电量 >50%，无断连 |
| 遥控器低电 | 电池放到 3.5V | OLED 报警 + 蜂鸣，飞机仍可控制 |
| 失控 | 关机/拔电 | 300ms 后幅度归零；1s 后迫降 |
| 绑定 | 换一台遥控器 | 未绑定不能控制；绑定后正常 |
| 低电 | 可调电源降到 3.4V | 遥测报警，状态机进迫降 |
