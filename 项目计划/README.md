# 仿生蝴蝶 · 总体方案与实施档案

基于你打开的嘉立创 EDA 工程 `SCH_V521_Footprint`（ESP32-C3 + 双路 8.4V 舵机驱动 + 九轴传感器 + 1S 锂电升压）做的整机方案。

> **当前状态**：方案/选型/结构文档已完成；**固件代码按你的要求暂未开写**，等你确认后再动手。
> 最终收敛：**暂不考虑树莓派**、**舵机性价比优先**、**纯无线遥控**、**只靠两个舵机拍翅起飞且升力有余量**、**翼尽量小**。

## 1. 结论摘要

| 你问的 | 结论 | 详细 |
|---|---|---|
| 飞控算法怎么最稳 | **Mahony 互补滤波 + 串级 PID（角速度 400Hz / 角度 100Hz）+ 拍翅相位同步前馈 + 增益调度**。不上 EKF：单核 C3 算力不划算、强周期振动下反而易发散 | [01-飞控算法选型](docs/01-飞控算法选型.md) |
| 用什么舵机（性价比优先） | **2× 国产 HV（8.4V）数码金属齿，8–13 g，≥1.8 kg·cm、≥700 °/s（≤0.085 s/60°），30–60 元/个**。核心思路：**把设计点从 8 Hz 降到 7.5 Hz**，舵机从 120 元档降到 30–60 元档，T/W 仍有 1.54。**4.8–6V 舵机接 8.4V 会烧** | [02-舵机与拍翅机构选型](docs/02-舵机与拍翅机构选型.md) |
| 遥控用什么通信 | **ESP-NOW 纯无线**：遥控器是独立电池手持设备（不插任何线），50Hz、端到端 25–35 ms、双向遥测；板上 SBUS 口可接成品接收机做备份 | [03-遥控链路与协议](docs/03-遥控链路与协议.md) |
| 仅靠舵机能否起飞 | 能。**490 mm 翼 + 75 g + 7.5 Hz：T/W = 1.54**；即使舵机只有 0.09 s/60°，7.1 Hz 时 T/W 仍有 1.38（起飞只需 >1.2） | [05-翼型实测与尺寸校核](docs/05-翼型实测与尺寸校核.md) |
| 翼能多小 | 按"全重 ×1.3 升力余量"反算：**75–80 g 最小翼展约 480–500 mm**。你的 490 mm 图刚好，**不用改大** | [04-总体结构与装配](docs/04-总体结构与装配.md) |

**最终设计点：**

| 参数 | 数值 |
|---|---|
| 翼展 / 全重 | **490 mm / 75 g**（72–80 g） |
| 翼面积 / 翼载 | 0.136 m² / 0.55 kg/m² |
| 拍翅 / 翼角 | **7.5 Hz（上限 8）/ ±60°**，机械限位 ±68° |
| 推重比 T/W | **1.54**（设计目标 ≥1.3） |
| 传动 | i=4（舵机臂 5 mm / 摇臂 20 mm），舵机 ±15° |
| 舵机 | 2× HV 数码金属齿，≥1.8 kg·cm、≥700 °/s、8–13 g、30–60 元级 |
| 电池 / 功耗 | 1S 500 mAh 30C / 9–11 W，续航 4–6 min |
| CG | 距翼最前点 140–160 mm |
| 链路 | ESP-NOW 50 Hz + 20 Hz 遥测，遥控器独立供电 |
| 控制 | Mahony + 串级 PID + 相位前馈，400/100/50 Hz 分频 |

## 2. 硬件速览（从原理图核对出来的）

| 模块 | 器件 | 关键结论 |
|---|---|---|
| 主控 | ESP32-C3-MINI（单核 RISC-V + WiFi/BLE） | 原生 USB：IO18/IO19 |
| 姿态 | MPU6500 | **SPI**：SCLK=IO6、MOSI=IO5、MISO=IO4、CS=IO7；INT 未接 → 轮询 |
| 磁/气压 | LIS2MDL + SPL06-001 | I2C：SCL=IO2、SDA=IO3 |
| 舵机输出 | 2 路：P3/P4（信号 + 8.4V + GND） | PWM_L=IO1、PWM_R=IO8，**经光耦反相** |
| 电源 | TP4067 / TPS61088 / AMS1117-5V / AP2112-3.3V / TPS22965 | 1S 锂电 → 8.4V 舵机；负载开关 5.7 V / 6 A（本方案 3 A 以内，安全） |
| 其他 | ADC_BAT=IO0（2:1 分压）、LED=IO10、BOOT=IO9、SBUS 反相进 RXD0 | 完整引脚表见 [00 文档](docs/00-原理图解读与引脚表.md) |

## 6. 免责 & 使用建议

- 文档里气动/机构数字是一阶估算，**误差 ±40% 很正常**，必须用 02 文档第 6 节的台架测试回填。
- 便宜舵机**标称参数普遍虚高**：买回来先测速度（0.09 s/60° 为合格线），不合格就退换。
- 舵机必须 HV（7.4–8.4V），4.8–6V 的接板上 8.4V 会烧；逻辑电平要兼容 3.3V。
- 试飞先系绳，戴护目镜，电池放防爆袋；遥控器与飞机全程不插线，失控保护先在地面验证。
